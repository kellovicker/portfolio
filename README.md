# Kingsley Chindah — Portfolio (React + Vite)

    npm install
    npm run dev

1. Add your photos: `public/images/hero.png` (hero) and `public/images/about.png` (about card)
2. Edit `src/data.js` — email, social links, projects, skills, services
3. Project screenshots: drop into `public/projects/` and set `image: '/projects/name.png'`
